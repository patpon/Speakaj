# Speakaj — แค่พูด ไม่ต้องพิมพ์

Desktop voice dictation for Windows and macOS (Thai + English). Hold a key, speak, release — clean text is typed into whatever app you're using.

Work in progress: full README, landing page, and installers coming next.

```bash
pip install -r requirements.txt
python -m speakaj --setup
python -m speakaj
```
