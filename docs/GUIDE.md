# Speakaj — แค่พูด ไม่ต้องพิมพ์

> โปรแกรมพิมพ์ด้วยเสียง ภาษาไทย + English สำหรับ Windows และ Mac
> กดปุ่มค้าง → พูด → ปล่อย ข้อความที่เรียบเรียงแล้วจะพิมพ์ลงช่องที่เคอร์เซอร์อยู่ทันที

**[⬇️ ดาวน์โหลดสำหรับ Windows](https://github.com/patpon/Speakaj/releases/latest/download/Speakaj-Setup.exe)** · [Mac](https://github.com/patpon/Speakaj/releases/latest/download/Speakaj-macos.zip) · เวอร์ชันล่าสุด 0.2.5

---

## ส่วนที่ 1 · ข้อความสำหรับหน้าเว็บ

### หัวเรื่อง (Hero)

- **หัวข้อใหญ่:** แค่พูด ไม่ต้องพิมพ์
- **คำโปรย:** กดปุ่มค้างไว้ พูดตามปกติ แล้วปล่อย ข้อความที่เรียบเรียงแล้วจะพิมพ์ลงช่องที่เคอร์เซอร์อยู่ ใช้ได้กับ LINE, Excel, Gmail และทุกโปรแกรม
- **ปุ่มหลัก:** ดาวน์โหลดสำหรับ Windows (30 MB)
- **ปุ่มรอง:** สำหรับ Mac
- **บรรทัดเล็กใต้ปุ่ม:** ฟรี · ไม่ต้องสมัครสมาชิก · ติดตั้งเสร็จในไม่กี่คลิก

### ตัวอย่างการทำงาน

| สิ่งที่พูด | สิ่งที่พิมพ์ให้ |
|---|---|
| “~~เอ่อ~~ พรุ่งนี้ ~~อืม~~ ประชุมสาขา ตอนบ่ายสองนะครับ ~~แล้วก็ แล้วก็~~ ฝากส่ง report ยอดขาย มาก่อนเที่ยง” | พรุ่งนี้ประชุมสาขาตอนบ่ายสองนะครับ ฝากส่ง report ยอดขายมาก่อนเที่ยง |

### จุดเด่นเป็นตัวเลข

| ตัวเลข | คำอธิบาย |
|---|---|
| **1–2 วิ** | ปล่อยปุ่มแล้วข้อความขึ้น |
| **ไทย + EN** | พูดปนกันในประโยคเดียวได้ |
| **ทุกโปรแกรม** | ช่องไหนพิมพ์ได้ ช่องนั้นพูดได้ |
| **0 บาท** | ไม่มีค่าสมาชิกรายเดือน |

### ใช้ง่าย 3 ขั้นตอน

1. **กดค้าง** — กด **Ctrl ขวา** หรือ **Pause** ค้างไว้ จะมีแถบเล็กขึ้นว่า “กำลังฟัง…”
2. **พูดตามธรรมชาติ** — ไม่ต้องพูดช้า ไม่ต้องบอกวรรคตอน พูดไทยปนคำอังกฤษได้ตามปกติ
3. **ปล่อยปุ่ม** — คำว่า เอ่อ อืม และคำพูดซ้ำถูกตัดออก แล้วข้อความพิมพ์ลงช่องให้ทันที

### งานที่พูดแทนพิมพ์ได้

- **LINE ตอบลูกค้า:** “รับทราบครับ ของจะส่งถึงร้านพรุ่งนี้ช่วงเช้า”
- **อีเมล:** “เรียนทุกสาขา ขอให้ส่งยอดขายประจำสัปดาห์ภายในวันศุกร์นี้ ขอบคุณครับ”
- **Excel หมายเหตุ:** “สาขาขอนแก่น สต็อกขนมปังแซนด์วิชเหลือน้อย ต้องเติมก่อนวันจันทร์”
- **ChatGPT / Claude:** “ช่วยสรุปรายงานนี้เป็นข้อๆ ให้หัวหน้าอ่านได้ในหนึ่งนาที”

**ใช้ได้กับ:** LINE · Word · Excel · Google Sheets · Gmail · Outlook · Facebook · ChatGPT · Claude · Notion · Notepad · ทุกช่องที่พิมพ์ได้

### ทำไมต้อง Speakaj

- **ฟังภาษาไทยเข้าใจ** — แยกไทยกับอังกฤษให้เอง ใส่คำเฉพาะ เช่น ชื่อสินค้าหรือชื่อสาขา ให้ฟังแม่นขึ้นได้
- **เกลาคำให้อัตโนมัติ** — ตัด เอ่อ อืม และคำซ้ำ ข้อความออกมาพร้อมส่ง
- **ใช้ได้กับแป้นภาษาไทย** — ไม่ต้องสลับภาษาแป้นพิมพ์ก่อนพูด
- **ใช้ได้กับทุกคีย์บอร์ด** — เลือกปุ่มกดค้างได้หลายปุ่ม คีย์บอร์ดที่ไม่มี Ctrl ขวาใช้ปุ่ม Pause แทนได้
- **เปิดเร็ว เปิดพร้อมเครื่อง** — อยู่เงียบๆ เป็นไอคอนไมค์ข้างนาฬิกา
- **ติดตั้ง-ถอนง่าย** — ติดตั้งด้วย Next ไม่กี่ครั้ง ถอนได้จาก Settings → Apps เหมือนโปรแกรมทั่วไป
- **ข้อมูลอยู่ในเครื่องคุณ** — ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์เก็บข้อความ

### คำถามที่พบบ่อย

**ใช้ฟรีจริงไหม?**
ตัวโปรแกรมฟรี ผู้ทดลองใช้รหัสทดลองที่ได้รับ ไม่ต้องมี API key เอง

**ต้องต่ออินเทอร์เน็ตไหม?**
ต้องต่อ เพราะเสียงถูกส่งไปแปลงเป็นข้อความแล้วส่งกลับมา ใช้เวลาประมาณ 1–2 วินาที

**เสียงของฉันถูกเก็บไว้ที่ไหน?**
เสียงถูกส่งไปแปลงเป็นข้อความเท่านั้น ไม่ถูกเก็บไว้ ข้อความที่ได้เก็บเป็นประวัติในเครื่องคุณเครื่องเดียว

**ใช้กับโปรแกรมไหนได้บ้าง?**
ทุกโปรแกรมที่มีช่องให้พิมพ์ เพราะ Speakaj วางข้อความเหมือนเรากด Ctrl+V เอง

**คีย์บอร์ดไม่มีปุ่ม Ctrl ขวา ทำอย่างไร?**
ใช้ปุ่ม **Pause** ได้เลย (เปิดไว้ให้ตั้งแต่แรก) หรือกด **F9** ครั้งเดียวเพื่อเริ่ม กดอีกครั้งเพื่อหยุด

## ส่วนที่ 2 · คู่มือการใช้งาน (เวอร์ชัน 0.2.5)

### 1. ติดตั้ง (Windows)

1. ดาวน์โหลด **[Speakaj-Setup.exe](https://github.com/patpon/Speakaj/releases/latest/download/Speakaj-Setup.exe)**
2. ดับเบิลคลิกเปิดไฟล์
   - ถ้าขึ้นหน้าจอสีฟ้า “Windows protected your PC” ให้กด **More info → Run anyway** (ขึ้นเพราะไฟล์ยังไม่มีลายเซ็นดิจิทัล)
3. กด **Next** จนจบ
   - ☑️ *Create a desktop shortcut* = มีไอคอนบนหน้าจอ
   - ☑️ *Start Speakaj when Windows starts* = เปิดเองทุกครั้งที่เปิดเครื่อง
4. กด **Finish** โปรแกรมจะเปิดขึ้นมาเอง

> ไม่ต้องใช้สิทธิ์ admin · ติดตั้งเวอร์ชันใหม่ทับของเดิมได้เลย ค่าที่ตั้งไว้ยังอยู่

### 2. ตั้งค่าครั้งแรก

หน้าต่าง **Speakaj — ตั้งค่า** จะเด้งขึ้นมา

1. ช่อง **รหัสทดลอง** ใส่รหัสที่ได้รับ เช่น `DEMO-AB12-CD34`
2. **ปุ่มกดค้างเพื่อพูด** ติ๊กปุ่มที่จะใช้ (เลือกได้หลายปุ่ม)

   | ปุ่ม | หมายเหตุ |
   |---|---|
   | ☑️ Ctrl ขวา | ค่าเริ่มต้น |
   | ☑️ Pause | ค่าเริ่มต้น เหมาะกับคีย์บอร์ดที่ไม่มี Ctrl ขวา |
   | ☐ Scroll Lock | ไฟ Scroll Lock บนคีย์บอร์ดจะติด/ดับทุกครั้งที่กด |
   | ☐ F8 | ชนกับคำสั่งใน Excel |

3. กด **บันทึกและเริ่มใช้งาน**

> มี Groq API key ของตัวเอง? กดลิงก์ **“มี API key ของตัวเอง? คลิกที่นี่”** แล้วใส่แทนรหัสทดลองได้

### 3. ใช้งานทุกวัน

1. คลิกในช่องที่จะพิมพ์ เช่น แชต LINE, เซลล์ Excel, อีเมล
2. **กดปุ่มที่เลือกค้างไว้** (Ctrl ขวา หรือ Pause) → แถบขึ้นว่า “กำลังฟัง…”
3. **พูด**
4. **ปล่อยปุ่ม** → “กำลังแปลงเสียง…” → ข้อความพิมพ์ลงช่องใน 1–2 วินาที ✅

**พูดยาวๆ ไม่อยากกดค้าง:** กด **F9** หนึ่งครั้งเพื่อเริ่ม พูดจบกด **F9** อีกครั้ง

### 4. เมนูไอคอนไมค์

คลิก **^** ที่มุมขวาล่างของจอ (ข้างนาฬิกา) → **คลิกขวา** ไอคอนวงกลมน้ำเงินรูปไมค์

| เมนู | ใช้ทำอะไร |
|---|---|
| สัปดาห์นี้: N คำ | ดูว่าสัปดาห์นี้พูดไปกี่คำ |
| คัดลอกข้อความล่าสุด | ถ้าข้อความไม่ขึ้นในช่อง กดเมนูนี้แล้ว Ctrl+V วางเอง |
| เปลี่ยนรหัสทดลอง / API key… | แก้รหัสที่ใส่ผิด หรือเปลี่ยนปุ่มกดค้าง |
| เปิดไฟล์ตั้งค่า | ตั้งค่าขั้นสูง (สำหรับผู้ชำนาญ) |
| เปิดโฟลเดอร์ประวัติ | ดูประวัติข้อความที่พูด |
| ออก | ปิดโปรแกรม |

### 5. ข้อความแจ้งเตือนที่อาจเห็น

| ข้อความ | ความหมาย / วิธีแก้ |
|---|---|
| รหัสทดลองไม่ถูกต้อง | พิมพ์รหัสผิด → เมนูไอคอนไมค์ → **เปลี่ยนรหัสทดลอง** |
| หมดระยะทดลองใช้แล้ว | ครบระยะทดลอง → ติดต่อผู้ให้รหัสเพื่อต่ออายุ |
| ใช้ครบ N ครั้งของวันนี้แล้ว | ครบโควต้ารายวัน → ใช้ต่อได้พรุ่งนี้ |
| รหัสทดลองนี้ถูกยกเลิกแล้ว | ติดต่อผู้ให้รหัส |
| เปิดไมค์ไม่ได้ | เช็คว่าเสียบไมค์/หูฟังแล้ว และ Windows อนุญาตให้ใช้ไมค์ (Settings → Privacy → Microphone) |
| วางข้อความไม่ได้ (คัดลอกไว้แล้ว) | กด **Ctrl+V** วางเองได้เลย |

### 6. แก้ปัญหาเบื้องต้น

- **กดปุ่มแล้วไม่มีอะไรเกิดขึ้น** → ดูว่ามีไอคอนไมค์ข้างนาฬิกาไหม ถ้าไม่มี ให้เปิด Speakaj จากไอคอนบน Desktop
- **คีย์บอร์ดไม่มี Ctrl ขวา** → ใช้ **Pause** หรือ **F9**
- **ข้อความไม่ขึ้นในโปรแกรมที่เปิดแบบ Run as administrator** → ต้องเปิด Speakaj แบบ admin ด้วย
- **ภาษาไทยฟังผิดบางคำ** → พูดให้ชัด ใกล้ไมค์ขึ้น หรือแจ้งผู้ดูแลให้เพิ่มคำเฉพาะ
- **ต้องการส่งให้ผู้ดูแลตรวจ** → กด `Win + R` พิมพ์ `%USERPROFILE%\.speakaj` → ส่งไฟล์ `speakaj.log`

### 7. ถอนการติดตั้ง

**Settings → Apps → Installed apps → Speakaj → Uninstall**

ระบบจะลบโปรแกรม ไอคอน การตั้งค่า รหัสทดลอง และประวัติทั้งหมด ไม่เหลือค้างในเครื่อง

## ส่วนที่ 3 · สำหรับผู้ดูแล (แจกรหัสทดลอง)

1. เปิด **https://speakaj-relay.patcharapon-pst.workers.dev/admin** → ใส่รหัสผ่านผู้ดูแล → **เข้าสู่ระบบ**
2. ใส่ชื่อผู้ทดลอง → (จะใส่ “ทดลองได้กี่วัน” และ “วันละกี่ครั้ง” หรือเว้นว่างไว้ก็ได้) → **สร้างรหัสทดลอง**
3. ส่งให้ผู้ทดลอง 2 อย่าง: ลิงก์ดาวน์โหลด Setup.exe + รหัสทดลอง
4. จัดการภายหลังได้ทุกเมื่อ: แก้จำนวนวัน/ครั้ง → **บันทึก** · กด **ยกเลิก** เพื่อปิดสิทธิ์ทันที

> จำนวนวันเริ่มนับตั้งแต่ผู้ทดลองใช้ครั้งแรก · โควต้าฟรีของบริการแปลงเสียงประมาณ 2,000 ครั้ง/วัน นับรวมทุกคน

**ข้อความส่งให้ผู้ทดลอง (ก๊อปไปใช้ได้เลย)**

```
ทดลองใช้ Speakaj — แค่พูด ไม่ต้องพิมพ์
1. โหลด: https://github.com/patpon/Speakaj/releases/latest/download/Speakaj-Setup.exe
2. เปิดไฟล์ (ถ้าขึ้นเตือนสีฟ้า กด More info → Run anyway) แล้วกด Next จนจบ
3. ช่อง "รหัสทดลอง" ใส่: DEMO-XXXX-XXXX → กดบันทึก
4. คลิกช่องที่จะพิมพ์ กด Ctrl ขวา หรือ Pause ค้าง พูด แล้วปล่อย
5. เลิกใช้: Settings → Apps → Speakaj → Uninstall
```
