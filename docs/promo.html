ใช้ง่าย สามจังหวะ

ไม่ต้องเปิดหน้าต่างใหม่ ไม่ต้องสลับโปรแกรม ทำงานอยู่ตรงไหนก็พูดได้ตรงนั้น

กดค้าง

กด Ctrl ขวา ค้างไว้ จะมีแถบเล็กขึ้นว่า “กำลังฟัง…” หรือกด F9 ครั้งเดียวเมื่ออยากพูดยาวๆ

พูดตามธรรมชาติ

ไม่ต้องพูดช้า ไม่ต้องบอกวรรคตอน พูดไทยปนคำอังกฤษอย่าง report, meeting ได้ตามปกติ

ปล่อยปุ่ม

คำว่า เอ่อ อืม คำพูดซ้ำ ถูกตัดออก แล้วข้อความพิมพ์ลงช่องให้ทันที

งานที่เคยพิมพ์ทั้งวัน พูดแทนได้เลย

เหมาะกับคนที่ตอบแชต เขียนอีเมล หรือจดงานเยอะ แต่ไม่อยากนั่งจิ้มคีย์บอร์ด

LINE ตอบลูกค้ารับทราบครับ ของจะส่งถึงร้านพรุ่งนี้ช่วงเช้า ถ้ามีปัญหาโทรหาผมได้เลยครับ
Gmail / Outlookเรียนทุกสาขา ขอให้ส่งยอดขายประจำสัปดาห์ภายในวันศุกร์นี้ ขอบคุณครับ
Excel หมายเหตุสาขาขอนแก่น สต็อกขนมปังแซนด์วิชเหลือน้อย ต้องเติมก่อนวันจันทร์
ChatGPT / Claudeช่วยสรุปรายงานนี้เป็นข้อๆ สั้นๆ ให้หัวหน้าอ่านได้ในหนึ่งนาที

ทำไมต้อง Speakaj

ฟังภาษาไทยเข้าใจ

ใช้ Whisper large-v3 แยกไทยกับอังกฤษให้เอง เพิ่มคำเฉพาะ เช่น ชื่อสินค้าหรือชื่อสาขา ให้ฟังแม่นขึ้นได้

เกลาคำให้อัตโนมัติ

ตัดคำว่า เอ่อ อืม และคำซ้ำ ใส่ Claude API key เพิ่มได้ ถ้าอยากให้เรียบเรียงและใส่วรรคตอนละเอียดขึ้น

ใช้ได้กับแป้นภาษาไทย

ไม่ต้องสลับภาษาแป้นพิมพ์ก่อนพูด เปิดแป้นไทยค้างไว้ก็พิมพ์ได้ปกติ

เปิดพร้อมเครื่อง

ตั้งให้เปิดเองตอนเปิดคอม แล้วอยู่เงียบๆ เป็นไอคอนไมค์ข้างนาฬิกา

ข้อมูลอยู่ในเครื่องคุณ

API key และประวัติเก็บในเครื่อง ไม่มีเซิร์ฟเวอร์กลาง ไม่ต้องสมัครบัญชีกับเรา

โค้ดเปิดให้ดู

Open source สัญญาอนุญาต MIT ตรวจสอบได้ทุกบรรทัดบน GitHub

เริ่มพูดแทนพิมพ์ได้ภายใน 5 นาที

เวอร์ชัน 0.1.0 · Windows 10/11 และ macOS

ดาวน์โหลด Windows ดาวน์โหลด Mac
  1. แตกไฟล์ zip แล้วดับเบิลคลิก Speakaj.exe
  2. ถ้า Windows เตือน ให้กด More info → Run anyway
  3. ขอ Groq API key ฟรีที่ console.groq.com/keys แล้ววางในหน้าต่างตั้งค่า
  4. คลิกช่องที่จะพิมพ์ กด Ctrl ขวาค้าง แล้วพูดได้เลย

คำถามที่พบบ่อย

ใช้ฟรีจริงไหม

ตัวโปรแกรมฟรี การแปลงเสียงใช้ Groq แบบฟรี ไม่ต้องใส่บัตรเครดิต ได้ประมาณ 2,000 ครั้งต่อวัน ถ้าใส่ Claude API key เพื่อเกลาข้อความ ส่วนนั้นจ่ายตามที่ใช้จริง

ต้องต่ออินเทอร์เน็ตไหม

ต้องต่อ เพราะเสียงถูกส่งไปแปลงเป็นข้อความที่ Groq แล้วส่งกลับมา ใช้เวลาประมาณ 1–2 วินาที

เสียงของฉันถูกเก็บไว้ที่ไหน

Speakaj ไม่มีเซิร์ฟเวอร์ของตัวเอง เสียงส่งตรงไปที่ Groq ด้วย key ของคุณ ข้อความที่ได้เก็บเป็นประวัติในเครื่องคุณเท่านั้น

ใช้กับโปรแกรมไหนได้บ้าง

ทุกโปรแกรมที่มีช่องให้พิมพ์ เพราะ Speakaj วางข้อความเหมือนเรากด Ctrl+V เอง
